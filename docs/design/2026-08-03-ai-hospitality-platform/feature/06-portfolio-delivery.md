## 任务 3: 准备三段式面试演示

**文件**:
- 创建: `DEMO_SCRIPT.md`
- 创建: 2–3 分钟备用录屏

**实现**:
```md
1. 顾客端：复杂需求 -> 实时推荐 -> 预订预填
```

## 任务 4: 用真实指标生成简历表述

**文件**:
- 创建: `AI_EVAL_REPORT.md`
- 创建: 简历 bullet 草稿

**实现**:
```md
- 基于流式 Tool Calling 构建 AI 选房顾问，将自然语言约束转为实时库存查询与生成式推荐 UI。
- 构建权限感知运营 Copilot，以 KPI、图表、订单卡和人工审批呈现工具执行结果。
- 建立 N 条 Eval，实际工具选择正确率 X%、越权阻断率 100%、P95 延迟 Y 秒、单次成本 Z。
```

只有 N/X/Y/Z 已由最终报告测得时才替换占位符；不虚构用户增长、转化率和商业收益。

**验证**:
- 运行: 将简历每个数字追溯到报告或构建产物
- 检查: 面试时能解释每项指标的测量方法、失败样本和改进过程
