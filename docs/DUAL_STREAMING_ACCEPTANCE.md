本地交互验收使用可控 HTTP fixture，不请求真实 Gemini、库存或审批数据库。这一层可以观察停止、断流和滚动，但不替代真实模型与线上代理链路的验证。

人工顺序：先实时展示，再停止/恢复，然后阅读/窄屏，最后审批与普通业务回归。一次只验一项，失败时保留已经通过的记录，修复后重验失败项及受影响项。
