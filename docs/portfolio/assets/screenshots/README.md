# Fixture Screenshot Manifest

These eight PNG files are generated by Playwright against the real UI with intercepted HTTP fixtures. They are versionable product-state evidence, but they do **not** prove a real model call, real database authorization, production deployment, or user outcome. The UUIDs, access token, employee identity and feedback receipt used by these tests are synthetic.
