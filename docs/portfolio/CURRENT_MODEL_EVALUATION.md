# 当前百炼模型评测与成本

核验日期：2026-10-08。三个生成入口使用 `qwen3.7-plus` 非思考模式，政策向量为 `text-embedding-v4` / 768维。本报告把当前模型与历史 Gemini 指标分开。

## 固定流式场景

真实调用当前百炼模型，注入合成库存/政策工具及不写数据库的观测层。使用生产 Concierge 指令与 Agent；输出评测上限为每次1024 Token，生产4096上限保持。覆盖缺失信息、人数、低预算、空库存、日期冲突、注入拒绝、未知政策、工具故障与需求修改。回答判定是固定断言，不是语义裁判或用户满意度。

| 批次 | 生成完成 | 场景断言 | 总耗时P50/P95 | 首段文字P50/P95 | 按实测Token估算原价成本 |
| --- | --- | --- | --- | --- | --- |
| [初始完整批次](https://github.com/notjustkoala/the-wild-oasis-website-ai/blob/main/tests/ai/reports/dashscope/2026-10-08-initial.json) | 10/10 | 6/10 | 8.471 / 13.686秒 | 3.112 / 5.840秒 | ¥0.105400 / 10场景 |
| [修复后独立完整批次](https://github.com/notjustkoala/the-wild-oasis-website-ai/blob/main/tests/ai/reports/dashscope/2026-10-08-final.json) | 10/10 | 10/10 | 6.987 / 13.677秒 | 2.872 / 4.134秒 | ¥0.107808 / 10场景 |

初始4项不是工具或网络失败：英文问题得到中文回答，缺失信息、预算、空结果与拒绝文本断言未通过。定向诊断确认后，指令明确英文问题全程英文，中文政策例子不得改变回复语言。4项定向补验通过后，重新独立执行完整10项，通过10/10。初始失败报告保留，不把两批合并成首次全部通过。

最终批次的工具选择10/10、所有适用搜索参数/结果约束通过；工具故障场景明确观察到1次合成工具失败后解释，不代表无错误。TTFT从开始调用Agent到第一段文字，可能包含工具前的说明；不是首卡片时间。测试在Windows通过当前代理访问北京模型，不能作为Vercel生产SLA。小样本P95按nearest-rank计算。

## 计费口径

按 [阿里云百炼官方模型价格](https://help.aliyun.com/zh/model-studio/model-pricing) 2026-10-08核验，北京地域、单次输入不超过256K、非思考生成的原价为：输入¥2/百万Token，输出¥8/百万Token；`text-embedding-v4` 输入¥0.5/百万Token。网页的限时优惠、缓存折扣、免费额度与账号合同价格不用于这份保守原价估算。超过256K输入需使用另一阶梯，不能套用本例。

```text
生成估算（元）= 输入Token×2÷1,000,000 + 输出Token×8÷1,000,000
向量估算（元）= 向量输入Token×0.5÷1,000,000
```

最终10个场景平均生成成本约¥0.010781/场景。多轮和多次工具步骤各自重复计输入，用量按所有步骤相加。缺失用量保留unknown/null；生成费用不包含查询向量、数据库、托管、税费等，也不是供应商账单。当前完整场景使用合成政策，没有运行embedding，因此不将向量费列为0成本的真实检索。

示例：单请求输入4000、输出500 Token，生成原价约¥0.012；查询向量输入100 Token约¥0.00005。单次真实对话成本取决于历史、政策片段和工具步骤，不能保证固定价格。

## 三个入口的证据范围

- Guest：上述真实模型/合成工具固定批次，以及已通过的生产选房、政策、预填与人工验收。
- Staff Copilot：真实生产SOP/多轮/运营查询和人工验收已有证据；本次固定10项只评测Guest，不将它们称为员工准确率。
- Admin Briefing：真实生产结构化输出/缓存/权限和人工验收已有证据；员工staff无权限是预期行为，不作为生成失败。
- Embedding：7篇/16块迁移、24条真实检索/RLS场景已完成；本次不重新生成整个向量库或重复收费校准。

三个入口的生产运行聚合和按Token估算已在本地核对；包含开发验收流量，不是随机真实用户实验，实际运行明细保持本地。不发布身份、客人资料、原文或实际运行ID。

## 复现

在Guest/BFF项目配置server-only百炼环境后：

```powershell
npm run eval:ai:dashscope -- --live
# 只补指定固定场景（新批次，不覆盖历史）：
npm run eval:ai:dashscope -- --live --case live-01-missing
```

入口默认拒绝未显式`--live`的执行；仅接受目录内场景。每次最多32个模型请求，输出最多1024 Token/请求、输入按UTF-8字节保守预留，累计最多预留¥1；达到边界时停止，不伪造通过。供应商错误后不反复重放整个批次。报告写入ignored `output/closeout`，原始合成回答仅供本地诊断，发布指标需检查数据范围。
